这 8 份文本用于批量评测生成管线（前 5 份是初版语料，06–08 为 10-18 追加），目的只有一个：量出"一次通过率"和延迟分布。
内容由通用电气调试常识编写，**参数全部为虚构示例值**，不来自任何企业内部资料。

例外：`04_hvac_cooling.txt` 的生成产物已上架为迁移验证案例
（`data/samples/hvac_cooling.json`，`g_hvac_cooling_check`），来源登记见 `docs/SOURCES.md` D-04；
其余 7 份仅用于评测，不进入案例库、不对外展示。

选这 5 类的理由：
1. 车门开关门功能 —— 判据是时间/状态，最典型；
2. 车门防夹功能 —— 含阈值与动作序列，考"步骤是否可执行"；
3. 车门隔离与紧急解锁 —— 含安全联锁，考"安全项会不会被漏掉"；
4. 空调制冷 —— 换子系统，考 `system` 枚举与术语迁移；
5. 受电弓升降 —— 换子系统，考"升/降"对称动作会不会写反。

如果只测车门，模型可能只是把这一个场景背下来了。
