# 视觉规范（as-built）

> 版本 v1.0 · 最后更新：2026-10-23 · 适用范围：`apps/electro-assist/web`
> 本文是**代码现状**的说明，不是设计愿望清单：所有令牌取自 `src/styles/tokens.css`，
> 组件规格取自 `base.css` 与各视图的 `<style scoped>`。设计稿里未落地的部分集中列在 §9。
> 与本文配套：`UX.md`（行为与状态）、`FRONTEND.md`（工程结构）。

## 1. 定位

**工业仪表盘式的克制**：像一块校准过的万用表——信息密、对比强、没有装饰性动效。

| 原则 | 含义 | 为什么 |
|---|---|---|
| 读数优先于氛围 | 装饰不得与数值争夺对比度；正文 ≥4.5:1，判据数值 ≥7:1 | 强光、戴手套、单手操作，只有 2 秒扫视窗口 |
| 一色一义 | 青绿=动作，琥珀=注意，红=危险，绿=通过 | 电气行业颜色本身是安全语言，多义即误判 |
| 结构靠边框，层次靠留白 | 1px 边框 + 背景色阶；阴影只两级 | 步骤卡连排时重阴影会糊成"卡片汤"，打印也脏 |

深色**只出现在顶部 48px 导航条与页脚**，内容区一律浅色。这样面试官看到的是门户的同一套基因，
工程师看到的是能打印的白纸。

## 2. 令牌（唯一来源 `tokens.css`）

### 2.1 颜色

| 语义 | Token | 值 | 用途 |
|---|---|---|---|
| 主色 | `--c-primary` | `#0B6E78` | 主按钮、进行中、链接、图示标注线（对白 6.0:1） |
| 主色-文字 | `--c-primary-ink` | `#075159` | 链接 hover、主色底上的强调文字 |
| 主色-淡 | `--c-primary-soft` / `--c-primary-line` | `#EAF5F6` / `#B9DADE` | 选中行、气泡、tag 底 |
| 页面底 | `--c-bg` | `#F6F8F9` | 内容区 |
| 表面 | `--c-surface` | `#FFFFFF` | 卡片、输入框、表格 |
| 描边 | `--c-line` / `--c-line-soft` | `#DFE5E8` / `#EEF2F4` | 默认描边 / 行分隔 |
| 文字一级 | `--c-ink` | `#12181C` | 标题、判据数值 |
| 文字二级 | `--c-ink-2` | `#3D4A52` | 正文 |
| 文字三级 | `--c-ink-3` | `#626F78` | 说明、时间戳、单位（对白 5.17:1，12px 小字也过 AA） |
| 成功 | `--c-success` / `-soft` | `#157F3D` / `#E8F4EC` | 判据通过、作业完成 |
| 警告 | `--c-warning` / `-soft` / `-line` | `#A85B00` / `#FFF4E0` / `#F0D3A6` | 临界、需复测、未发布 |
| 危险 | `--c-danger` / `-soft` | `#C0262A` / `#FBECEB` | 判据不合格、异常分支、停止作业 |

**红色的纪律**：只允许超限、异常入口、破坏性操作、带电区域；禁止用于取消/返回、进度、链接、装饰。
危险按钮必须带文字动词（"停止作业"），不许纯红图标。

### 2.2 字体

```css
--font-sans: -apple-system, BlinkMacSystemFont, "Segoe UI", "PingFang SC",
  "Hiragino Sans GB", "Microsoft YaHei", "Noto Sans CJK SC", sans-serif;
--font-mono: ui-monospace, SFMono-Regular, "SF Mono", Menlo, Consolas,
  "Liberation Mono", monospace;
```

零外链、零在线字体。中文不加负字距；数值一律 `font-variant-numeric: tabular-nums`，否则表格列不对齐。

| 层级 | 字号/行高 | 字重 | 用途 |
|---|---|---|---|
| H1 | 22/30 | 600 | 页面标题 |
| H2 | 18/26 | 600 | 区块标题 |
| H3 | 16/24 | 600 | 卡片、步骤卡标题 |
| 正文 | 15/24 | 400 | 中文平板可读下限 |
| 辅助 | 13/19 | 400–500 | 表单标签、表头、胶囊 |
| 说明 | 12/18 | 400 | 时间戳、单位、脚注（不小于 12px） |
| 数据 | 15–20 mono | 600 | 判据读数、记录编号、坐标 |

### 2.3 间距 / 圆角 / 阴影 / 尺寸

间距只用 4 的倍数（4/8/12/16/20/24/32/48），不出现 5/10/14/18。

| Token | 值 | 说明 |
|---|---|---|
| `--radius-sm` | 6px | 输入框、tag、小按钮 |
| `--radius` | 10px | 卡片、图示容器（上限，不用 12/16/20） |
| `--shadow-1` | `0 1px 2px rgba(18,24,28,.06)` | 卡片默认 |
| `--shadow-2` | `0 4px 16px rgba(18,24,28,.08)` | 浮层、进行中的步骤卡 |
| `--tap` | 44px（A1 现场 48px） | 所有可点目标下限 |
| `--nav-h` | 48px | 顶部条高度，逃生条与 `sticky` 共用同一变量 |
| `--w-content` | 860px | 内容列宽（指导书是读物，不是仪表盘） |
| `--w-figure` | 520px | 图示容器最大宽 |

禁止：彩色发光、`inset` 阴影做内凹、同一元素同时用边框 + 重阴影表达同一层级。

## 3. 组件

| 组件 | 规格 |
|---|---|
| 主按钮 | h40（现场 48）· padding 0 20 · `--radius-sm` · 14/500 · `--c-primary` 底白字；按下 `scale(.99)`；禁用改 `--c-line-soft` 底 + 灰字；加载时左侧 14px spinner，**宽度不跳动** |
| 次按钮 | h40 · 白底 + `--c-line` 描边 + `--c-ink`；hover 边框加深、底 `--c-bg`；不用灰实心底（会与禁用混淆） |
| 危险按钮 | 次按钮结构，文字/描边换 `--c-danger`；破坏性确认才用实心底 |
| 卡片 | 白底 · 1px `--c-line` · `--radius` · padding 20 · `--shadow-1`；可点卡片 hover 只换描边与阴影，**不位移** |
| 步骤卡（A1 核心） | 左 3px 状态条 · 32×32 mono 序号 + H3 + 右侧胶囊 · 底部操作右对齐；待执行灰条、进行中主色条 + `--shadow-2`、通过成功色、异常危险色 + `--c-danger-soft` 底。**同时只有 1 张卡处于进行中** |

| 状态胶囊 | h22 · padding 0 8 · 999px · 12/500 · `-soft` 底 + `-line` 描边 + `-fg` 字；**图标 + 文字 + 颜色三重编码**（色盲可用） |
| 进度 | 分段式：每步一段 · h4 · 轨道 `#E7EAEF` · 完成/当前主色（当前 60% 透明）· 右侧 `3/8` mono |
| 骨架屏 | 底 `#EDEFF3` + 1.4s 线性扫光；**行高与真实字段一致**，避免加载后跳动；只用于长任务 |
| 结论卡（B） | 不进气泡，独立白卡 + 1px 描边；含条目、检查顺序（有序列表）、升级条件、安全提示与"来自人工整理知识库"标注 |

## 4. SVG 原语（13 个）

`StepCard` / `Meter` / `StatusLight` / `Wiring` / `Connector` / `TorqueGauge` / `Checklist` /
`MotionTimeline` / `FlowArrow` / `Callout` / `GateState` / `Table` / `Annotation`，
由 `figures/registry.ts` 按 `primitive` 映射，未知类型降级为"无图版"而不是空白。
参数白名单与语义校验在 `models/visual.py`：键名不在白名单、必填缺失、表格行列不齐，一律拒绝。

| 原语 | 用途 | 关键约束 |
|---|---|---|
| `motion_timeline` | 分段动作时序 | `steps` 2–6 项；竖排，时间写在原文里，不做坐标换算 |
| `flow_arrow` | 操作先后顺序 | `steps` 2–5 项；每行最多 3 个，超出换行 |
| `callout` | 单点强调 | `target` + `note` 必填；`position` 取 left/right/top/bottom |
| `gate_state` | 开关/门到位状态 | `state` 取 open/closed/half；文字标签恒显示，颜色只是第二重编码 |
| `table` | 参数对照 | `headers` 2–4 列，`rows` 每行用 `|` 分格且格数必须相等 |
| `annotation` | 部位标注 | `points` 1–6 项；只画编号点与图例，不画设备轮廓（没有几何信息） |

| 元素 | 规则 |
|---|---|
| 线宽 | 主结构 1.5px；次级（柜体轮廓、地面）1px；引线 1px |
| 颜色 | 主结构 `#3D4A52`；次级 `--c-line`；标注引线 `--c-primary`；带电区 45° 斜纹 |
| 接点 | 圆 r=2.5，白填充 + 1.5px 描边；端子号 11px mono 置于接点上方 4px |
| 标注 | 水平折角引线，末端 4×4 三角；文字 11/16，**永远水平不旋转** |
| 文字 | 图内不用纯黑、不用衬线；文字不压线（留 8px） |
| 打印 | 彩色转 `#000`/`#555`，斜纹转网点，阴影全去 |

内联 SVG（继承 `currentColor`、可打印、零请求），不用位图、不用 `<img>`。

## 5. 导航与双端结构

顶部条与底部操作条**同为 48px 但色彩相反**，这是刻意的语义分离：
深色可点=会离开当前页，白色可点=推进当前步。

| 部件 | 规格 |
|---|---|
| 顶部条 | h48 · `#12181C` · 底部 1px `rgba(255,255,255,.10)` · padding 0 16 · `sticky top:0` · `z-index:30` · **不加阴影** |
| 导航项 | 品牌 + 「生成指导书」+「故障排查」+「返回门户」；当前项白字 600，非当前 `rgba(255,255,255,.78)`；窄屏品牌换短标题，全部 `nowrap` |
| 底部操作条（A1） | 白底 · 上边框 1px `--c-line` · 向上投影 · h48 + padding 8 16 + `env(safe-area-inset-bottom)` · `z-index:20`；主按钮独占整行；内容区底padding 预留 64px |
| 层级 | 顶部条 30 > 抽屉 40（未实现）> 底栏 20 |
| 页脚 | 深色，13/19，一句合规声明 |

## 6. 动效

| 用途 | 时长 / 缓动 |
|---|---|
| 反馈（按下、勾选） | 120ms `cubic-bezier(.16,1,.3,1)`，只改底色/透明度/`scale(.99)` |
| 过渡（展开、切卡） | 240ms，位移上限 8px |
| 引导注意 | 单次 320ms 高亮，**不循环、不发光、不缩放卡片** |

全站无视差、无无限循环；`transition` 不作用于 `box-shadow` 与 `height`；
`@media (prefers-reduced-motion: reduce)` 下动画/过渡压到 0.01ms（已在 `base.css` 落地）。

## 7. 打印

`print.css` 由路由动态加载，规则全包在 `@media print`。

- `@page { size: A4; margin: 12mm }`；正文 11pt / 1.5
- 隐藏 `.site-nav`、`.site-foot`、`.no-print`（按钮、底栏、错误条）
- 卡片去边框去阴影，图示去底去圆角，线宽不变
- 步骤卡 `break-inside: avoid`，标题 `break-after: avoid`
- 素材图 `break-inside: avoid`、`max-height: 80mm`；文末「现场素材」区随图成块，不跨页
- 打印时强制亮色令牌（`--c-bg:#FFF`、`--c-ink:#000`…），否则深色皮肤会打出黑底
- 记录页页眉用 `<thead>` 内单行（左编号 / 右时间 / 0.75pt 分隔线），**不做页码**——
  `position:fixed` 在 Chromium 打印只出首页，`@page` margin box 支持面太窄
- `content-visibility: auto` 在打印时必须还原为 `visible`，否则出空白页

## 8. 验收口径（含 2026-10-23 实测）

- 对比度：正文 ≥4.5:1、判据数值 ≥7:1、非文字 ≥3:1 —— 实测 axe **0 violation**（4 页 × 2 视口）
- 触摸目标：通用 ≥44×44，A1 现场 ≥48×48
- 打印：Chromium 逐页翻——无半截卡片、二页起表头仍在、图示无灰底、正文 ≥10pt
- 首屏：JS ≤75KB gzip、CSS ≤14KB gzip —— 实测 **41.47KB / 6.10KB**
- Lighthouse Mobile：Perf ≥90、LCP ≤2.0s、CLS ≤0.05 —— 线上实测库页 **100 / 1.31s / 0**、指导书页 **99 / 1.29s / 0**
- 焦点可见：键盘 Tab 全程可见 2px 主色环（`:focus-visible`）

> 数据来源与复现命令：`apps/electro-assist/web/scripts/lighthouse.mjs`、`scripts/axe.mjs`；
> 结论与原始数据见私有仓 `reports/性能与可访问性实测-2026-10-23.md`。

## 9. 未落地的规格（as-built 差异，写清楚免得文档说谎）

| 规格 | 现状 | 处置 |
|---|---|---|
| 暗色皮肤 + A1 逃生条 | **未实现**，只有亮色 `:root` | 判"不做"：现场用机常为深色模式，自动变暗会让户外可读性失效；手动开关的收益低于维护成本 |
