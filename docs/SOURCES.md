## 规则

1. 任何进入演示的工艺内容，必须在此登记：来源类型、链接或出处、获取日期、改写程度。
2. **不得使用企业内部资料**（图纸、作业指导书、故障记录、工艺卡等）。
3. 公开资料进入案例前必须**虚构化改写**：改型号、改数值量级、改部件称呼，保留结构与方法。
4. 页面与文档中必须保留「演示数据 · 非实际作业依据」声明。
